# Fontes

- `WorkSans_800ExtraBold.ttf`: título, data e categorias.
- `WorkSans_500Medium.ttf`: resumo e crédito.

Work Sans (Wei Huang), licença SIL Open Font License 1.1. Obtida do pacote npm `@expo-google-fonts/work-sans` 0.4.2 (licença do pacote MIT AND OFL-1.1).

Escolha provisória: a fonte original da arte aprovada não estava disponível. Entre nove famílias abertas testadas (Work Sans, Montserrat, Poppins, Inter, Nunito Sans, Open Sans, Lato, Roboto, Raleway), Work Sans teve a maior sobreposição de tinta com o texto da referência. Trocar quando a fonte original for entregue; basta atualizar os caminhos em `layout-spec*.json`.
